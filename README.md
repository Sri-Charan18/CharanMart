# CharanMart

Online multi-seller shopping website where buyers can browse, order and pay, sellers can manage products, and admin can monitor users and orders.

## Demo login (password: password123)

- Admin: admin@charanmart.com
- Seller: ravi@charanmart.com
- Buyer: amit@charanmart.com

## Run

```bash
mvn clean package
```

Deploy the WAR `target/CharanMart.war` to Apache Tomcat 9, then open:

http://localhost:8080/CharanMart/
